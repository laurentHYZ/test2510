What the product is

A single-page Tetris game delivered as one self-contained HTML document. I inspected the live page directly: it loads one inline script (~27 KB) and one inline stylesheet, references no external scripts or fonts, and makes no network requests other than its own favicon. It is a fully offline-capable web app whose entire distribution is one file that can be opened from disk, e-mailed, or served from any static host.

Feature set

  • 10×20 playfield, 7-bag randomiser
  • Super Rotation System with full wall-kick tables
  • Ghost piece, hold slot, 3-piece next preview
  • Lock delay (500 ms, up to 15 resets)
  • Guideline scoring: 100/300/500/800 × level, back-to-back and combo bonuses
  • Level up every 10 lines, 15-step gravity curve
  • Chiptune sound effects synthesised in-browser with the Web Audio API — no audio files
  • Best score persisted in localStorage
  • Bilingual UI (Simplified Chinese / English), Chinese default, choice remembered
  • Responsive dark UI with on-screen touch controls

Technical highlights

  • One file, no build step. No bundler, no package manifest, no dependencies to patch or audit.
  • No supply chain. Zero third-party code, zero external requests — nothing to compromise downstream.
  • Trivial distribution. Any static host, any CDN, or a local file; works offline and on locked-down networks.
  • Small. 34 KB of HTML including markup, styles and engine — sub-second load on any connection.
  • Standards-only stack. Canvas rendering, Web Audio, localStorage: no framework lock-in.
