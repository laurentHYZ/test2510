Ce qu’est le produit

Un jeu de Tetris sur une seule page, livré sous la forme d’un document HTML autonome. J’ai inspecté la page en direct : elle charge un unique script intégré (~27 Ko) et une feuille de style intégrée, ne référence aucun script ni police externe, et n’émet aucune requête réseau en dehors de son propre favicon. C’est une application web entièrement utilisable hors connexion, dont toute la distribution tient dans un seul fichier que l’on peut ouvrir depuis un disque, envoyer par courriel ou servir depuis n’importe quel hébergeur statique.

Fonctionnalités

  • Terrain 10×20, générateur aléatoire « 7-bag »
  • Système de rotation SRS avec tables de wall-kick complètes
  • Pièce fantôme, emplacement de réserve, aperçu des 3 pièces suivantes
  • Délai de verrouillage (500 ms, jusqu’à 15 réinitialisations)
  • Score conforme aux règles : 100/300/500/800 × niveau, bonus back-to-back et combos
  • Niveau supérieur tous les 10 lignes, courbe de gravité en 15 paliers
  • Effets sonores chiptune synthétisés dans le navigateur via la Web Audio API — aucun fichier audio
  • Meilleur score conservé dans localStorage
  • Interface bilingue (chinois simplifié / anglais), chinois par défaut, choix mémorisé
  • Interface sombre responsive avec commandes tactiles à l’écran

Points techniques

  • Un seul fichier, aucune compilation. Ni bundler, ni manifeste de paquets, ni dépendance à corriger ou à auditer.
  • Aucune chaîne d’approvisionnement. Zéro code tiers, zéro requête externe — rien à compromettre en aval.
  • Distribution triviale. N’importe quel hébergeur statique, n’importe quel CDN, ou un simple fichier local ; fonctionne hors connexion et sur les réseaux verrouillés.
  • Compact. 34 Ko d’HTML incluant le balisage, les styles et le moteur — chargement instantané sur toute connexion.
  • Uniquement des standards. Rendu Canvas, Web Audio, localStorage : aucune dépendance à un framework.

Risques visibles dans l’état actuel

Ce projet est un clone non licencié utilisant le nom 俄罗斯方块/Tetris ; le présenter commercialement sans licence expose à un risque juridique qu’un conseil d’investisseur identifiera immédiatement. Aucun fichier de licence dans le dépôt, donc « tous droits réservés » par défaut — droits flous pour les utilisateurs et les contributeurs. Aucune description, page d’accueil, thématique, badge de README ni version publiée sur le dépôt : le produit n’a aucun habillage. Aucune instrumentation de distribution ni de mesure : rien ne compte les utilisateurs, les sessions ou la rétention, donc aucune affirmation de croissance ne peut être étayée aujourd’hui.
